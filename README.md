# The Terminal

a little horror game that plays like a terminal. you connect to an old prediction machine from 1999 called n.o.d.e. and poke around its files while it tries to predict what you're gonna do next. read the wrong file and it hits you with PREDICTION FAILED. there's hidden folders, a bunch of lore to piece together, and four endings. it also remembers how many times you've come back, which is the creepiest part.

## how to play

just open index.html in a browser, or play it here:

https://mateooo93.github.io/N.O.D.E/

you type commands and read what comes back. mostly you just explore and try to figure out what actually happened in this place.

## commands

```
ls
cat <file>
cd <dir>
cd ..
model
status
help
clear
exit
```

some files and folders are hidden and won't show up in ls. you have to guess the names or find hints written in the other files. also not every command is listed.

type null and see what happens.
