# The Terminal

a little puzzle-horror game that plays like a terminal. you connect to an old prediction machine from 1999 called n.o.d.e. and you poke around its files trying to figure out what actually happened here. it's a puzzle game, not a story you just read. the clues are scattered across the files, some folders are hidden, and the machine keeps leaving little predictions about what you'll do next.

you win by figuring the whole thing out. if you just do what the machine expects you to, it wins instead.

## how to play

open index.html in a browser, or play here:

https://mateooo93.github.io/N.O.D.E/

type commands and read what comes back. if you get stuck, type hint and it nudges you toward the next step.

## commands

```
ls
cat <file>
cd <dir>
cd ..
model
status
hint
help
clear
exit
```

a few folders and files are hidden and won't show up in ls. you have to find their names in other files, or follow the predictions. also not every command is listed.

trust nothing.
